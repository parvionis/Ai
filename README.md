# 🌌 PARVIONIS — Every Problem, One Solution

**PARVIONIS** is an all-in-one, macOS-inspired glassmorphic AI web platform designed for young learners (10+) and modern problem-solvers. Combining structured academic breakdowns, file analysis, and adaptive multi-threaded chat, PARVIONIS balances deep pedagogical clarity with Vedic philosophy and psychological insights.

Created with ❤️ by **Amanjot Singh**.

---

## ✨ Key Features

* 💬 **ChatGPT & Gemini-Style Interface**: Multi-threaded sidebar navigation, message actions, instant response rendering, and history saving.
* 🔒 **Admin-Restricted AI Training (`@train`)**: Live system instruction injection protected by local authentication and secret administrator overrides.
* 📁 **Document & File Analysis**: Upload text files, code scripts, or documents directly into the chat engine for real-time extraction and context processing.
* 🧸 **ELI5 Mode**: Instant toggle to break down complex concepts into simple, age-appropriate explanations.
* 📝 **Notes & Cheat Sheet Engine**: Generate structured, high-yield revision guides and study sheets automatically.
* 🔐 **Local Auth System**: Persistent user accounts and guest mode isolation using browser local storage.
* 🎨 **macOS Glassmorphism UI**: Interactive canvas background, responsive micro-animations, dynamic light/dark contrast, and a custom geometric SVG identity.

---

## 🛠️ Built With

* **HTML5 / CSS3 / Modern JavaScript (ES6+)**
* **Tailwind CSS** (Utility Styling)
